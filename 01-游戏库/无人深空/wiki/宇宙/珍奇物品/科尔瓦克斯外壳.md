Summary

Korvax Casing is a curiosity of Korvax origin.

Game Description

The metallic shell of a disconnected electronic lifeform that was too distant from its kind to be refreshed with a new entity.

Highly prized by all species, not least its own.

Sources
The simplest way to get Korvax Casings in large amounts is to buy it from pilot NPCs in any Trading Post found in Korvax systems.
Can be found in Damaged Containers or as monolith rewards.
A possible reward from frigate expeditions.
A possible trade from wandering traders you encounter while using the Pulse Engine.
With a 10% chance from crew lockers in Derelict Freighters.
Use
Can be given to Korvax NPCs to increase the player's standing with Korvax faction.
Can be used when interacting with a monolith in Korvax systems to reveal the location of the portal for the planet.
Crafting

Korvax Casing is used as an ingredient for crafting the following products:

 Consciousness Bridge  --  Hexite x250  +  Pugneum x80  +  Korvax Casing x1  →   Consciousness Bridge
Refining

Korvax Casing is not used as an ingredient for refining using a Refiner.

Cooking

Korvax Casing is not used as an ingredient for cooking using a Nutrient Processor.

Additional Information

Can be used on monolith:

 Gek Relic
 Vy'keen Dagger
 Korvax Casing

Can't be used on monolith:

 GekNip
 Vy'keen Effigy
 Convergence Cube
See Also
 Convergence Cube - Korvax-specific trade commodity.
 Gek Relic - equivalent item for Gek faction.
 Vy'keen Effigy - equivalent item for Vy'keen faction.
Release History
Release - Introduced to the game.
Living Ship - Added Space Encounter with traders as a possible source.
