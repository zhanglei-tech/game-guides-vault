# 物种

> 原页版本标签：回声；原页修订 `1239331`（2025-09-08）。

原页使用 物种 统称《无人深空》的植物和动物。它们不是逐个手工设计，而是由算法根据玩家、周边区域、环境和位置等因素组合生成；外观可从生物发光蘑菇、草木到巨型陆生动物和小型鱼类。

## 动物互动

- 使用 生物颗粒 喂食动物后可建立友好关系。
- 友好动物可供玩家收养或骑乘，并可能排出 屎球菌 或指出附近兴趣点。
- 动物死亡后仍可扫描；击杀通常获得 腐藤。
- 敌对动物以红色爪印提示，会在进入范围后攻击；食物可用于分散其注意力。

## 收养与同伴

- 喂食后可把生物登记为同伴，之后从同伴注册表召唤。
- 在空间站、太空异象或货船等不允许实体生物活动的区域，召唤时可能只显示同伴全息影像。
- 同伴会跟随玩家，可被互动、玩耍，并安装装饰性部件。
- 已收养或已建立友好关系的动物不能被玩家杀死。
- 放弃同伴需要在 同伴登记处 中移除，而不是通过伤害处理。
- 同伴 更新后不再为不同动物属准备专用诱饵，统一使用颗粒。

## 植物互动

- 多数植物可用开采光束取得 碳 及其他资源。
- 扫描植物和岩石可揭示次级可开采资源；揭示后，同类对象都可产出该资源。
- 明亮花朵通常可直接采集特定生存资源。
- 部分危险植物会攻击或伤害靠近的玩家。
- 草通常只是地表背景，不计入可扫描植物。

## 六种智慧物种

| 物种 | 常见位置与特点 |
| --- | --- |
| 盖克 | 三大主导种族之一，有语言、剧情和声望 |
| 科尔瓦克斯 | 三大主导种族之一，有语言、剧情和声望 |
| 维吉恩 | 三大主导种族之一，有语言、剧情和声望 |
| 旅行者 | 神秘旅行者，可在多种地点遇见 |
| 异常 | 玩家默认外观所属类别；非玩家角色 表现方式特殊 |
| 自噬体 | 需特定扫描条件和营地剧情才能正常接触 |

除 异象者 与 自噬体 的出现方式特殊外，多数智慧物种可在空间站和建筑兴趣点遇到。帮助三大种族或正确处理纪念碑互动，可提升声望并取得设计图、货币、地点、语言词汇和护盾充能等服务；也可能通过互动得到不同飞船和多用途工具。

## 动物分类与发现

- 原页记录游戏有 35 个动物 属／属级类型，完整分类放在 动物群 页面。
- 扫描所有动物可完成一颗星球的动物发现；地基 后只有动物计入“扫描全部物种”的完成度，植物和矿物不提高该百分比。
- 动物群 名人堂 维护社区记录的最大和最小动物，但属于动态玩家发现目录，本地页不复制。
- 原页推测动物叫声也由程序生成，声音受生物形状和大小影响；这是社区推测而非已确认机制。

## 植物大类

原页把多数植物概括为六类：

1. 蘑菇型；
2. 葫芦朵／球状花型；
3. 树型；
4. 蕨类；
5. 珊瑚扇型；
6. 危险植物型，常呈触手形并攻击玩家。

同一大类会因星球而改变尺寸、形状、颜色和细节，同一颗星球也可生成多个变体。

## 版本沿革

- 初始版本：物种系统随首发加入。
- 地基：明确只有动物计入星球“扫描所有物种”完成度。
- 同伴：取消按动物属区分的专用诱饵，统一使用 生物颗粒，并扩展收养和同伴功能。
