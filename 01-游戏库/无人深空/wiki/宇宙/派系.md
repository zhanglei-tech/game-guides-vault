# 派系

> 原页版本标签：虫群；原页修订 `1327839`（2026-07-29）。

原页把 派系 与 种族 并用，指具有智慧、语言、剧情和技术传统的物种。当前共列出六种：科尔瓦克斯、吉克、维吉恩、自噬体、旅行者 和 异象者。护卫扮演警察力量，但不被视为可建立声望的真正派系。

## 六种派系

| 派系 | 原页描述 | 技术或互动特点 |
| --- | --- | --- |
| 科尔瓦克斯 | 近乎不朽的机器生命，重视科学和探索，崇拜 阿特拉斯，接受护卫存在 | 擅长套装技术 |
| 盖克 | 两栖智慧物种，重视商业；古代 初生种 曾追求银河统治 | 擅长飞船技术 |
| 维吉恩 | 军事化、荣誉体系严格，强烈仇恨护卫 | 擅长多用途工具技术 |
| 自噬体 | 由废料构成的机器生命，需要特殊扫描技术才能在营地看见 | 使用 虚空微粒，可取得 伏打法杖 和护甲外观 |
| 旅行者 | 近来抵达银河系的自由探索者，起源和目的不明 | 没有常规派系声望 |
| 异常 | 戴头盔、真实外观和起源不明；玩家默认外观 | 没有 非玩家角色 个体，只能在线遇到其他玩家扮演的 异象者 |

三大种族控制普通恒星系；一个系统只有一个主导派系。主导派系也会影响空间站到访飞船的多数类型。玩家可与前三者及 自噬体 建立关系，但 科尔瓦克斯 声望不会自动改变 吉克 或 维吉恩 声望，因为三者不是直接敌对的共享数值。

## 提高声望

- 完成对应种族恒星系任务板上的任务。
- 向该种族成员赠送专属礼物。
- 正确解决 生产设施、石碑、废墟、巨石、行动中心 等地点的问题。
- 在该派系领地击杀海盗。
- 从海盗手中救援货船。
- 在建筑中收集 研究样本。

自噬体 没有空间站任务板，取得声望的方式包括：

- 与营地成员交谈，接受本地行星合约；
- 在对话窗口赠送其专属礼物；
- 清除部分“受腐化”科尔瓦克斯 巨石 的腐化；
- 帮助落单、受困的 自噬体；
- 练习 自噬体 语言。

## 降低声望

- 摧毁对应派系的商船。
- 解错 巨石 问题。
- 摧毁货船舰队中的小型单引擎货船。
- 拒绝接受礼物。
- 从 维吉恩 非玩家角色 处拿走多用途工具；原页同时指出某些情形反而会增加声望，因此结果取决于对话。
- 练习语言时选择威胁性词语，例如对 吉克 使者说“摧毁”。

## 声望的游戏效果

- 决定部分设计图是否可购买。
- 解锁派系专属对话选项。
- 决定是否满足某些任务的最低声望要求。
- 高声望时，玩家遭海盗攻击可能获得援助。
- 在空间站购买技术模块时获得折扣。

跨平台联机 更新后，即使达到最高声望，后续敌对行为仍可使其下降。

## 练习语言

与特定派系成员对话可选择练习语言。可说的词取决于玩家已学会的该语言词汇；非玩家角色 会根据选词产生不同反应，包括赠送物品、技术升级或改变声望。

## 派系礼物

- 科尔瓦克斯：科尔瓦克斯外壳、科尔瓦克斯集会方型箱。
- 吉克：吉克小吸、吉克遗物。
- 维吉恩：维吉恩雕像、维吉恩匕首。
- 自噬体／相关互动：亚特兰蒂姆。

礼物可换取坠毁飞船位置、资源、货币和声望。

## 派系关系与历史

原页通过任务对话总结三大种族的历史关系：

- 维吉恩 长期对抗护卫，也记恨 吉克 初生种 的暴行。
- 初生种 摧毁 科尔瓦克斯 主型，奴役 科尔瓦克斯，并把其机体熔炼为 纳米星团。
- 大量 科尔瓦克斯 牺牲自身，把纳米血液混入未出生的 吉克，改变其行为倾向；现代 吉克 的贸易冲动被描述为由战争冲动转化而来。
- 吉克 后来成为 阿特拉斯 崇拜者。
- 纳达 明确拒绝用“敌人的敌人就是朋友”这种简单逻辑理解种族关系。
- 维吉恩 传统认为旅行者必须崛起，他们不应阻止旅行者的道路。

这些叙述来自游戏内角色和文本，不同叙述者带有自身立场，阅读时不应把单段对话当作无偏历史记录。

## 版本沿革

初始版本 加入 科尔瓦克斯、吉克、维吉恩；阿特拉斯 崛起 加入 旅行者；下一步 加入 异象者 并设为玩家默认外观；跨平台联机 允许最高声望再次下降；回声 加入 自噬体。
