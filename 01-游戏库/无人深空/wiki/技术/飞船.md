# 飞船

> 原页修订 `1328042`（2026-07-30）。飞船价格表、最大栏位和新类型更新频繁，本文保留机制与原页明确数值，不复制动态目录。

飞船用于星球起降、恒星系内脉冲飞行、跨系统跃迁、太空战斗和运输。外观、名称、等级、栏位和基础属性由程序生成；相似外观不保证相同库存或性能。

## 飞船类型

| 类型 | 典型强项 |
| --- | --- |
| 飞艇 | 发射消耗低，属性较均衡，适合早期过渡 |
| 战士 | 伤害加成高 |
| 探险家 | 超光速推进加成高，起飞消耗低 |
| 拖运船 | 护盾加成高，库存容量大 |
| 异星 | 多项属性高且均衡，外观稀有 |
| 活体 | 使用独立的活体技术与升级 |
| 太阳能 | 使用太阳帆，于亡命之徒更新加入 |
| 回收物 | 使用护卫技术，起飞消耗低；于拦截机更新加入 |
| 护卫舰 | 大型可组装飞船，于航行者号更新加入 |
| 货船 | 更接近移动基地，玩家不能直接驾驶或降落星球 |

> 术语说明：游戏内分类名称为“回收物”，玩家之间通常称为“拦截机”。

## 购买与折价

- 可在贸易站、空间站、小型聚落和货船机库等待非玩家角色的飞船。
- 价格取决于类型、栏位和等级，不取决于已装技术、个体加成、卖家或玩家声望。
- 与飞行员对话可预览后购买或用当前飞船折价。
- 原页记录折价为表定价值的 70%；若新船更便宜，不会退还差额。
- 坠毁飞船的损坏栏位会按比例降低折价。
- 重新载入可刷新到访飞船，但同一设计仍可能有不同栏位。

## 坠毁飞船

- 可免费认领并保留原飞船，不必强制交换。
- 基础技术和大量栏位通常损坏，完整修复的材料成本可能超过直接购买同类飞船。
- 可先逐格维修，或只修到能飞后用来折价／报废。
- 早期版本关于修复后换购的建议已因多次更新过时；NEXT 更新允许保留多艘飞船，合成更新加入飞船拆解终端。
- 原页还记录曾损坏后修复的武器伤害只有从未损坏版本的一半，这一旧行为是否仍适用于当前版本待确认。

## 核心技术

普通飞船通常预装：

- 发射推进器：用于起飞；普通难度每次约消耗 25%，生存／永久死亡约 50%。需要 40 铀才能充满。
- 脉冲驱动器：用于恒星系内高速飞行；需要 200 氚才能充满，原页估计可持续约 2 分钟。
- 光子大炮：基础太空武器。
- 偏导护盾：受伤后自动恢复，也可用催化元素或星盾电池立即补充。
- 超光速推进：用于跨恒星系跃迁；航路点更新后需要 4 个曲速电池才能充满，每次跃迁消耗 25%，曲速超核心可一次充满。

常见固定升级包括发射系统充能器（每分钟约充电 4%）、高效推进器（降低约 20% 起飞消耗）、亚光速放大器（脉冲速度约 +30%）、不稳定性驱动器（燃料效率约 +34%）、飞行辅助覆盖（机动性约 +11%）。

活体飞船对应技术为神经线路板、搏动心脏、喷口、尖叫抑制器和奇点主茎；移植眼类似相位光束。其升级体系与普通飞船分开。

## 等级、栏位与升级

- 等级为 C、B、A、S；等级越高，对应类型的核心属性和最大栏位通常越高。
- 可在飞船改装终端使用储备扩充增加栏位，也可花费纳米星团升级等级。
- 同一艘飞船升级后的核心属性由其类型规则和唯一种子决定，重复操作结果稳定。
- 航路点更新把通用栏与货物栏合并，并把最大技术栏位提高到 60、库存栏位提高到约 100—120。
- 玩家收藏上限在亡命之徒更新时为 9 艘，分形更新后提高到 12 艘。

## 飞船摧毁

- 普通模式在最近空间站重生，可跟随坟墓图标取回库存资源；海盗可能在抵达前抢走。
- 部分技术会损坏，脉冲驱动器 例外并会在重生时补充燃料。
- 生存模式永久失去飞船库存，并在最近星球上离坠毁飞船一段距离处醒来。
- 永久死亡模式飞船摧毁会结束游戏并删除存档。

## 飞船制造

轨道更新起，玩家可在空间站的飞船制造终端组装飞船。部件通过拆解其他飞船取得，反应堆核心从飞船技术商人处购买。

| 类型 | 所需部件 |
| --- | --- |
| 战士 | 机翼 1、船体 1、引擎 1、反应堆核心 1 |
| 探险家 | 左翼 1、右翼 1、船体 1、反应堆核心 1；左右翼可互换 |
| 拖运船 | 驾驶舱 1、引擎 1、机翼 1、反应堆核心 1 |
| 太阳能 | 主体 1、机翼 1、太阳帆 1、反应堆核心 1 |

不同类型的部件不能混用。可在完成前选择颜色；最终属性随机，类型加成固定，等级由反应堆核心决定。原页明确异星、活体和拦截机不能用这一终端制造。

## 版本沿革

探路者更新加入等级和折价；阿特拉斯崛起更新允许更低空飞行；NEXT 更新进一步降低飞行高度、移除环境飞船伤害并削弱海盗平均伤害；活体飞船更新加入活体飞船；亡命之徒更新加入太阳能飞船并扩大收藏上限；持久更新允许扩展活体飞船库存；分形更新将上限扩至 12 艘；拦截机更新加入回收物飞船；轨道更新加入飞船制造；后续版本加入护卫舰。
