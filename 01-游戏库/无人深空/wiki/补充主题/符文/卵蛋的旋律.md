# 卵蛋的旋律

> 本页为 英文原站 表格直连子页面的一层本地保存；中文名称参照无人深空灰机 维基，并结合当前简体中文客户端常用词校对。
## 中文整理

蛋的旋律是一个任务页面。

## 总结

卵蛋的旋律是一个任务，需要从水银合成伙伴那里以3200的价格购买虚空蛋来启动。

一旦购买了虚空蛋，玩家将在扭曲后开始在通讯器上收到随机消息。每条消息都将包含一个数字和字形名称。一旦收到全部十二个地址，玩家就可以使用该地址进入一个世界，在那里他们可以收到进一步的指示。

注意：生命之船任务“恒星的诞生”不需要此任务。它仅在虚空蛋在水银商店中可用期间和生命船更新发布期间才处于活动状态。

## 传输
传输似乎是在扭曲后随机到达的，并且需要几秒钟的时间才能发生。
传入的传输：“请旅行者听。”

- 十：现实的螺旋

## 行星地址
这些通向地址“0152:0081:05B9:00B4”，恒星系 Runanch-Gisa，行星 Erpetrith Raya。

一旦玩家到达星球，就会收到另一条消息，提供目的地的线索：
> *找到我们*
> 在孤独的水球上找到我们……
> 在北方达到顶峰的地方找到我们……
> 在鸡蛋不受喜爱的地方找到我们......
> *找到我们*

如果鸡蛋说的是更类似于：猎人 // 倒影 // 猎人 // 现实的螺旋 // 水面上的星星 // 上升的球体 // 被遮蔽的同伴 // 猎人 // 低等昆虫 // 异常 // 水手 // 海洋之王 // 欧几里得 欧几里得 欧几里得

然后继续访问地址：“026A:0084:0C16:0219”。

## 废弃建筑
这会导致北极附近的一座废弃建筑，行星坐标为+88.88，+13.70

到达目的地后，终端会给出信息：
> 你找到了我们的回声……
> 你很聪明，或者你很幸运。也许你是其中之一，也许你是许多人。
> 随着我们自身的成长，我们的回声也随之增强。
> 我们很快就会和你在一起。我们将一起旅行。
> 我们是你黑暗中的朋友。在星空中关注我们吧！

## 附加信息

《蛋的旋律》是《生命之船》更新发布的预告片。更新后，它被恒星的诞生任务取代。

有些玩家说他们已经在欧几里得之外的其他星系中完成了此操作，但从欧几里得中进行可能是最安全的。
