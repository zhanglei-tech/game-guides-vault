# 恒星的诞生

> 本页为 英文原站 表格直连子页面的一层本地保存；中文名称参照无人深空灰机 维基，并结合当前简体中文客户端常用词校对。
## 中文整理

恒星的诞生是一个任务页面。

## 总结

恒星的诞生是一项任务。玩家从水银合成伙伴处购买虚空蛋后，使用脉冲驱动器飞行，直至在太空遭遇一艘奇怪的星舰。虚空蛋随后转为活性状态并给出一系列坐标；玩家需要依次前往这些地点，学习新技术并重演一场早已被遗忘的科尔瓦克斯实验。由于多个生物器官都需要现实时间“成熟”，这是游戏中耗时最长的任务之一。

## 游戏说明

金属骨头上的肉

我从太空异象中带上了一颗蛋。从那时起，一种奇怪的意识，一种我无法理解的思想，在我的星舰中孕育而生。

它寻找宿主，生命与机器的融合体，因此它可能存在于回声之外……

我携带的奇怪的蛋呼唤着另一种有机体，一种星舰和生物的奇异混合体。

## 任务步骤

## 成熟神经干
虚空蛋变成活性虚空蛋。它现在嗡嗡作响奇怪的音乐，召唤我进入一个充满奇怪、闹鬼的地形和奇异色彩的世界。

从太空异象取得虚空蛋并在任意恒星系内飞行后，旅行者会在太空中遭遇一艘奇怪的外星星舰，并收到前往指定恒星系的路线和一组大致坐标。探索坐标附近区域可找到一块科尔瓦克斯牌匾。玩家需要向牌匾交付意识桥；牌匾会提供意识桥设计图，以及一处失事货船的位置，建造所需的己糖醇可在那里取得。带着意识桥返回牌匾后，玩家会得到脆弱的神经干，需等待约 18–25.5 小时使其成熟。

## 成熟心脏节点
虚空蛋变成了搅动虚空蛋。它现在嗡嗡作响奇怪的音乐，召唤我走向一个充满灰尘、火焰和冰的严酷世界。

脆弱的神经干成熟后，玩家会再次遭遇奇怪的星舰，并收到前往一颗极端贫瘠星球的路线和大致坐标。探索坐标附近区域可找到另一块科尔瓦克斯牌匾。玩家需要交付脉动核心；牌匾会提供脉动核心和太阳能射线的设计图。建造所需的液体太阳可用太阳能射线从金属矿床中提取。交付脉动核心后，玩家会得到脆弱的心，需等待约 19–25 小时使其成熟。

## 硬化外壳
虚空蛋变成了觉醒的虚空蛋。它现在哼着奇怪的音乐，召唤我走向天堂，一个充满生命和水的温柔世界。

脆弱的心成熟为成熟的心脏节点后，玩家会再次遭遇奇怪的星舰，并被引向一个可能已废弃的恒星系，其中有一颗极端丰饶星球。坐标会指向另一块科尔瓦克斯牌匾。玩家需要交付不可能的膜，牌匾会提供相应设计图。建造它需要催眠之眼和活水：催眠之眼可在标记出的水下废弃建筑取得，活水则要返回太空并与赫利俄斯之子互动获得。交付后会得到脆弱的外壳，需等待约 20–24 小时使其成熟。

## 奇点核心
虚空蛋变成了裂开的虚空蛋。它现在嗡嗡地唱着奇怪的音乐，让我的脑海里充满了一个移动星球的图像，前一分钟是草的世界，下一分钟是奇怪异常的世界。

脆弱的外壳成熟为硬化外壳后，玩家会再次遭遇奇怪的星舰，并被引向一颗“水力花园”类型的星球；实际星球类型有时会不同。随着玩家接近目标，大致坐标会逐渐精确，最终指向一处边界故障。玩家需要交付玻璃种子，现场会提供玻璃种子和阿尼玛斯光束的设计图。对生物使用阿尼玛斯光束可提取建造玻璃种子所需的破碎的感质。交付后会得到成长中的奇点，需等待约 18–26 小时使其成熟。

## 灵魂密室
鸡蛋吟唱着一首奇怪的歌曲，重复着：

猎人 // 倒影 // 猎人 // 现实的螺旋 // 水面上的星星 // 上升的球体 // 被遮蔽的同伴 // 猎人 // 卑微的昆虫 // 异常 // 水手 // 海洋之王 // 欧几里得 欧几里得 欧几里得

成长中的奇点成熟为奇点核心后，玩家会再次遭遇奇怪的星舰，并收到欧几里得银河系中的传送门坐标 `121905417A6B`（地址 `026A:0084:0C16:0219`）。该地址通往 Ischel-Althu 恒星系的 Axentha Sigma 星球。如果当前不在欧几里得银河系，必须先返回该银河系再使用传送门；加入一名已经位于目标恒星系的玩家也能更新任务。

到达后，玩家会收到坐标（-56.88，-159.20），该坐标通向废弃建筑。与终端互动后，玩家会收到一个灵魂密室，里面必须充满堕落旅行者的灵魂，需要 3 个灵魂。提供了下一个旅行者坟墓的大致坐标。坟墓的所有坐标都是随机生成的。灵魂密室充满后，就成为存档灵魂。如果玩家通过门户进入系统，则必须通过同一门户再次离开系统才能继续任务。

警告：收集第三个灵魂并通过传送门返回后，进入星舰会触发虚空蛋孵化，并让玩家选择“孵化”或“忽略”。建议先使用保存信标，或进入星舰后选择“忽略”再退出，以建立还原点，然后再按下文操作。

## 堕落宿主
在此步骤中，建议您立即进行手动保存[请参阅下面的推理]。

一旦玩家重新进入他们的星舰，就会收到一条新的通讯，让你选择孵化鸡蛋或忽略。如果您选择孵化，当前恒星系中将生成一艘活船，您将收到它的位置。它将是一个失事飞船地点，尽管它不是普通的星舰，而是一艘堕落宿主生物飞船。为了检查您是否对其外观感到满意，请使用快速菜单中的照片模式，这样您就不必退出 飞船 并覆盖您的手动保存。如果您不满意，请从菜单中的“选项”选项卡重新加载手动保存，通过传送或传送门旅行前往不同的系统，您将获得通往该系统中不同堕落宿主的新通信。 [参见星舰目录 - 生命舰以了解可能的位置以及发现的其他舰船的示例]。

如果对外观满意，退出当前星舰并与目标互动，执行“生物发生”，交付大脑、心脏、外壳、核心和灵魂。完成后即可像领取其他失事星舰一样免费取得这艘活体飞船。

## 打造你的完美飞船

可以反复读取还原点来抽取目标飞船，不必受限于每个恒星系只出现一艘。如果已知某颗星球上有符合需求的增压栏位布局，并且任务处于“堕落宿主”阶段、尚未接收信号，可按以下步骤操作：

1. 使用传送门坐标前往目标星球。
2. 立即离开星球并进入空间站。
3. 离开星舰以建立还原点。
4. 重新进入星舰并接收任务信号。
5. 任务会从已访问的星球中选择一颗，并随机给出地点。
6. 如果地点不符合需要，重新加载还原点并重复第 4 步。
7. 重复操作，直到任务标记给出目标活体飞船的坐标。
8. 完成任务并领取活体飞船。

可以通过登陆同一系统中的不同行星然后接受信号来改变所选择的行星。你目前所在的星球永远不会被选择。

## 附加信息

- 当“等待接触”时，在蓝星系统中使用脉冲驱动器是触发下一次遭遇的最快方式。 （实际最快的遭遇是使用异常扫描仪，因为它将保证几秒钟后进行通信，而不是罕见的太空异象遭遇。但不推荐这样做，因为异常探测器很少见。）
- 每次保存只能进行一次星际诞生。购买另一个虚空蛋将导致新的太空遭遇立即导致另一个堕落宿主，需要 10,000 个纳米星团才能认领这艘船。
- 完成远征 1 或远征 6 里程碑之一即可获得虚空蛋。
- 对于水银为 0 的玩家，完成恒星的诞生至少需要约八天：从周三开始，用四天完成枢纽日常任务并参加一次周末任务，以取得所需水银；此后各个生物飞船器官的成熟还需约四天。
- 任务期间学习和获得的全部新物品，其标价合计为 1,616 货币单位。
- 只要你的库存中有额外的虚空蛋，你就不需要为了额外的空间遭遇而扭曲。
- 任务的灵魂密室阶段要求玩家收集 16 个雕文中的前 12 个。这是因为任务要求玩家使用前 12 个字形中的一些，使用传送门前往特定坐标。这些字形可以通过与旅行者交谈并询问他们的坟墓位置，然后与这些坟墓互动来解锁；或者通过接近完成“净化”（阿尔忒弥斯之路的最终任务），在每次扭曲时接收雕文，直到拥有全部雕文。
- 自远征更新起，除欧几里得传送门地址和奇怪星舰的太空遭遇外，任务的其余阶段都改用目标扫描模式定位，大部分固定星球坐标已不再适用。
- 建议在收集你的活船之前保存，因为如果你不喜欢它，你可以重新加载并获得另一艘，直到你得到你想要的那艘。
- 通过将系统时钟提前 24 小时设置，可以跳过为活船生长部件之间所花费的等待时间。

## 错误

- 当从《星际诞生》初始任务中收集堕落宿主时，所有组件都必须位于玩家的活动库存中（套装、物品传输范围内的活动星舰货物或安装了物质束的货船货物槽），否则一艘机械船将在其位置生成。
  - 如果重新加载保存后问题仍然存在；
  1. 前往距离受影响恒星系至少 4,000 光年的地点，重置“堕落宿主”。
  2. 前往外星传送门并输入上文给出的符文地址。
  3. 再次通过传送门返回先前的恒星系。
  4. 起飞后，“堕落宿主”任务应在新恒星系重新触发。
- 如果活船重生未能覆盖机械星舰残骸，并且之前的情况不负有责任，则只要在与失事机械星舰进行任何交互之前进行重新加载的保存，重新加载游戏即可纠正该问题。
- 如果您距离当前任务目标太远并重新启动任务，有时会复制无效蛋。
- 有时，当您为巨石制作物品时，任务可能会出错并认为您距离太远。重新启动任务也会导致出现上述已知问题。
- 有时，当你要获得活船时（无论是通过任务还是获得一艘新船），目标可能会出现故障，给你一艘普通的船而不是一艘活船。
  - 这可能发生在你离开星球并返回之后。如果遇到这种情况，请尝试加载离开星舰后的最后一个恢复点；该星舰随后会恢复为当前星舰。
- 如果发育中的器官存放在货船或星舰中，而玩家距离载具足够远，计时结束时可能会复制：未成熟器官仍留在原库存中，成熟器官则出现在套装库存。
- 在生存模式下，如果未成熟器官仍在套装库存中，应尽量避免死亡，因为死亡会清除这些物品。
  - 这不适用于您的星舰/货船的库存，尽管计时器结束时未成熟的器官不会被成熟的器官取代。相反，您将收到成熟器官的新实例，而未成熟器官则永久存在。您可以将其保留为奖杯，因为您无法再次获得它，但这不是完成星际诞生的预期方式。

## 历史

- 活船 - 作为次要任务引入。
- 远征 - 完成远征 1 的一个里程碑可获得虚空蛋；不稳定的星球坐标改为大致位置。
- 亡命徒 - 虚空蛋成为远征 6 一个里程碑的奖励。
