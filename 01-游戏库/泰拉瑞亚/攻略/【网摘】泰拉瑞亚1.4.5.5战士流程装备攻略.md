# 战士流程装备攻略：从开局到月亮领主

> [!info] 来源与适用范围
> 整理自小黑盒作者 **天玟** 的《【1.4.5.5】史上最强战士流程装备推荐帖》。[查看原文](https://xiaoheihe.cn/app/bbs/link/8e6a719e45be)。
>
> 原文是面向**纯战士玩法**的实验性质装备推荐，整体偏向高生存，强调主手输出、功能性副手和坐骑配装。本文按阶段重组，保留武器定位、操作技巧与替换关系；强度排序和实战评价均属于原作者意见，不代表所有版本、难度与打法下的统一结论。
> 原文把**南瓜月、霜月、猪龙鱼公爵和光之女皇安排在石巨人后**，这是推荐顺序，不是它们最早能够挑战的时间。
> 本文不是全物品获取与合成百科。原文未展开的配方、掉率和获取条件不作补写；涉及 1.4.5 新武器与改动时，以实际游戏版本为准。

> [!warning] 饰品清单是候选池，不能全部照戴
> 原文多次按大师模式列出 **6 格／7 格**配置。专家模式初始 **5 格**，使用恶魔之心后为 **6 格**，需要删减。
> 同一节中列出的第八、第九项通常是替换项，不是额外的饰品栏。原文同时列出蠕虫围巾与混乱之脑时，也默认你已取得两种邪恶 Boss 的饰品，单一腐化世界不会自动同时拥有它们。

## 一、全流程速查

| 阶段 | 推荐主力／核心武器 | 防具方向 | 这一阶段解决什么 |
| --- | --- | --- | --- |
| Boss 前 | 星怒、草剑、荆棘旋刃 | 矿物套，或稽古衣散搭 | 先解决探索、安全输出与基础机动 |
| 邪恶 Boss 后 | 火山＋狱炎回旋镖 | 熔岩套 | 近距离爆发配合中远距离对单，准备骷髅王 |
| 骷髅王后 | 永夜刃 | 熔岩套 | 准备肉山，保留星怒与陨石光剑作功能副手 |
| 肉后初期 | 燧石、晶光刃 | 精金战士套 | 尽快换掉肉前输出，针对机械 Boss |
| 任意机械 Boss 后 | 光辉飞盘、叶列茨球；有则换更强悠悠球 | 神圣战士套 | 获得稳定中远距离输出 |
| 三机械 Boss 后 | 清怪用真圣剑；打花用飞盘／悠悠球 | 海龟套 | 把清怪武器和 Boss 武器分开 |
| 世纪之花后 | 泰拉刃＋吸血鬼刀＋钥匙剑 | 海龟套 | 全能输出、续航与地面辅助 |
| 石巨人后 | 泰拉刃；可选无头骑士剑、北极、飞龙 | 甲虫防御套为主 | 升级后期配装，挑战事件与可选 Boss |
| 月前 | 清柱用泰拉刃／飞龙；对月用破晓之光 | 甲虫防御套 | 根据目标切换主手 |

**读表方法：**不需要把每一件都刷齐。先选一件主力，再按需要补穿墙、恢复、地面清怪等功能副手。

## 二、先理解作者的配装思路

1. **战士可以同时携带多把不同用途的近战武器。**主手负责持续输出，星怒负责隔墙攻击，陨石光剑／晶光刃／钥匙剑承担插地辅助，吸血鬼刀负责恢复。
2. **机动有两条路线。**常规路线占用翅膀、气球、冲刺等饰品格；坐骑路线用坐骑承担主要移动，再把空出的格子换成生存或输出。
3. **高生存是这篇的风格。**蠕虫围巾、混乱之脑、星星面纱、盾牌、狂战士手套反复出现；缺输出时再考虑战士徽章、烈火手套等。
4. **悠悠球需要独立配装。**早期搭配白绳；后期作者优先保留悠悠球袋，通常从手套或其他输出格中替换。
5. **强度取决于打法。**光辉飞盘适合保持有效攻击距离；近身武器要等安全窗口；坐骑方案需要先熟悉操作。

## 三、Boss 前：先拿到顺手的探索武器

### 武器怎么选

| 武器 | 原文定位 | 使用要点 |
| --- | --- | --- |
| 附魔回旋镖 | 开局过渡 | 木回旋镖＋坠星；原文认为冰回旋镖、蘑菇回旋镖是更强的过渡选择 |
| 早期血腥／腐化悠悠球 | 中近距离过渡 | 搭配白绳使用 |
| 风暴长矛 | 少量敌怪的控制与输出 | 利用击退，保持合适距离 |
| 星怒 | 优先推荐 | 星星攻击方便处理丛林敌怪，也能照亮区域、辅助探图；贴近时也有输出 |
| 草剑 | 优先推荐 | 作者重视其高攻击频率与压制力，尤其推荐用于克苏鲁之脑；后续保留作永夜刃材料 |
| 荆棘旋刃 | 中远距离输出、地下清怪 | 面板高，地形弹射适合地下环境 |

其他可用过渡包括链球、腐化链球、腐叉、冰回旋镖、魔光剑、附魔剑等。**已有顺手武器就继续推进，不必收集齐全。**

原文认为 1.4.5 加强后的颌骨剑、时尚剪刀有强度，但操作负担大，所以没有放入主推荐路线。

![[天玟战士流程-原图01.jpeg]]

### 防具、饰品与坐骑

- **防具：**矿物套有啥穿啥，优先补防御。仙人掌套提供反伤，但不要把原文的换血评价当成安全战术。
- **稽古衣：**遇到旅商出售可考虑购买。原文列出的属性为 4 防御、5% 伤害、5% 暴击、10% 近战攻速、10% 移速；头腿可按现有装备散搭。
- **基础饰品：**跑鞋、二段跳／气球、魔光护符、猛爪手套；玩悠悠球再加白绳。
- **低成本填格：**原文建议多做白绳尝试获得好词缀，不使用悠悠球时也能作为前期过渡饰品。
- **坐骑候选：**疾旋鼬、轮滑鞋。作者用疾旋鼬的机动应对克苏鲁之眼、蜂王和骷髅王；是否替代跑鞋仍看自己的移动习惯。

### 星怒探索技巧

1. 星星发光可辅助观察地形和宝藏；作者也用它在安全位置处理黄蜂、毒刺史莱姆。
2. 若星星被上方物块挡住，可尝试把光标放在目标下方的空洞，调整落点。
3. 地表孤立的小水坑有时可作为上方浮空岛的寻找线索；原文建议用绳子向上探索。**这是找岛线索，不是每个水坑都对应空岛。**
4. 用星怒探索丛林仍有误触蜂巢内幼虫的风险，可提前在附近准备重生点。

## 四、邪恶 Boss 后：火山主攻，回旋镖补远程

### 武器组合

| 武器 | 用途 |
| --- | --- |
| 火山 | 原文首选主手，近距离爆发高，用来处理骷髅王双手 |
| 狱炎回旋镖 | 中远距离对单，适合骷髅王，也可应对蜂王 |
| 蜂巢球 | 若先打过蜂王，可作为类似定位的替代品 |
| 陨石光剑 | 投掷后可提前回收，当中距离穿透攻击；也可插地辅助拦截地面敌怪，原文称持续约 1 分钟 |
| 星怒 | 继续保留作穿墙与特殊地形副手 |

![[天玟战士流程-原图05.jpeg]]

**防具：**原文优先熔岩套，列出的整套属性为 25 防御、17% 近战伤害、7% 近战暴击、7% 近战攻速。

**饰品候选：**跑鞋、气球、魔光护符、猛爪手套、混乱之脑／蠕虫围巾、克苏鲁护盾。根据难度的实际饰品栏数量，按机动和生存需求取舍。

**坐骑：**继续用疾旋鼬或轮滑鞋；没有依赖坐骑冲刺时，可考虑保留克苏鲁护盾。

## 五、骷髅王后：永夜刃打肉山

### 主手与副手

- **永夜刃：**作者指定主手，用于单人肉山战。
- **陨石光剑：**继续作插地辅助武器。
- **星怒：**保留穿墙用途；作者认为多人肉山战中，饿鬼过厚导致永夜刃难以攻击本体时，可以考虑改用星怒。

![[天玟战士流程-原图09.jpeg]]

**防具：**继续穿熔岩套。

**饰品候选：**跑鞋、气球、混乱之脑／蠕虫围巾、黑曜石护盾、猛爪手套；骨头手套和克苏鲁护盾作为可选替换。原文认为永夜刃重视攻速，黑曜石护盾的击退免疫也很实用。

> [!warning] 跑道长度和换血能力是经验参考
> 原作者称单人大师肉山用永夜刃时，跑道至多约 400 格即可。但这取决于装备、增益、操作与版本，不能理解为通用上限。
> 多人饿鬼的具体血量也受难度和人数影响；本文保留「饿鬼挡输出时切换攻击方式」的思路，不把原文的血量描述当作固定数值。

## 六、肉后初期：尽快换成燧石与晶光刃

### 武器优先级

| 武器 | 原文优先级 | 主要用途与操作 |
| --- | --- | --- |
| 燧石 | 首选 | 原文认为无蓄力单击也有高输出，火柱可穿墙；对毁灭者与探针，以及机械骷髅王的转头阶段有针对性 |
| 晶光刃 | 首选 | 投掷攻击覆盖近距离区域，也能插地辅助；原文提到利用毁灭者尾部进行高伤害输出 |
| 香蕉回旋镖 | 次选 | 想要中远距离输出，或联机先打双子魔眼、机械骷髅王时考虑 |
| 暗影焰刀 | 次选 | 与香蕉回旋镖相近的远程定位，按实际获得情况互相替代 |
| 毁灭刃 | 过渡 | 刚击败肉山时处理普通敌怪，随后更换 |
| 永夜刃 | 过渡 | 不必立刻丢弃，但不要一直依靠肉前主手推进 |

![[天玟战士流程-原图13.jpeg]]

> [!note] 新武器和伤害评价
> 「燧石」「晶光刃」沿用原文名称。原文没有在正文展开获取配方，本文也不猜测材料。
> 作者提到燧石未蓄力攻击为 178% 伤害、成型后暴击可超过 500，以及晶光刃特定操作可快速击杀毁灭者。这些描述对应原文版本与配置，实际伤害随装备和战斗条件变化。

### 防具与饰品

**防具：**精金战士套。原文列出的整套属性为 50 防御、22% 近战伤害、14% 近战暴击、20% 近战攻速，作者认为其数值优秀。

| 路线 | 原文饰品候选池 | 取舍重点 |
| --- | --- | --- |
| 常规飞行 | 翅膀、气球、黑曜石护盾、星星面纱、蠕虫围巾、混乱之脑、狂战士手套 | 大师 7 格框架，专家需删一件 |
| 莉莉丝项链坐骑 | 气球、黑曜石护盾、星星面纱、蠕虫围巾、混乱之脑、狂战士手套、血肉指虎 | 用坐骑承担移动，空出的格子补生存 |
| 坐骑输出替换 | 战士徽章替换血肉指虎 | 原文建议在生存足够时补伤害 |

**莉莉丝项链：**作者强烈推荐，建议配合羽落使用，需要练习。用燧石水平拉扯双子魔眼时，原文也提到山羊、独角兽、莉莉丝、疾旋鼬等横向高机动坐骑。

## 七、任意机械 Boss 后：飞盘与悠悠球接管中远程

### 武器选择

| 武器 | 选择理由 | 注意事项 |
| --- | --- | --- |
| 光辉飞盘 | 中远距离稳定输出，作者认为略强于香蕉回旋镖 | 射弹数量有限，持续向远处风筝可能使回转不顺 |
| 叶列茨球 | 持续命中时输出可观 | 作者建议在丛林刷怪，也提到召唤史莱姆王增加刷取机会 |
| 代码 2、开发者悠悠球 | 获得后可替换叶列茨球 | 原文排序为「开发者＞代码 2＞叶列茨」，属于作者强度判断 |
| 燧石 | 机械 Boss 的近身输出窗口、穿墙 | 保留作特定场景武器 |
| 晶光刃 | 地面辅助 | 保留作插地副手 |

![[天玟战士流程-原图18.jpeg]]

**防具：**神圣战士套，原文重视套装闪避的生存价值。

**饰品：**延续肉后初期框架。常规路线可按材料升级蝴蝶之翼、蝙蝠之翼、蜜蜂之翼、烈焰之翼、喷气背包或开发者翅膀；原文将它们归在这一阶段，不代表获取条件和性能完全一致。

**用悠悠球时：**作者优先带悠悠球袋。常规路线从狂战士手套格替换；坐骑路线可替换血肉指虎或战士徽章。

> [!note] 「一王后」不等于所有物品都无条件解锁
> 如果第一只击败的机械 Boss 不是毁灭者，制作光辉飞盘仍要满足其材料条件。原文路线倾向先处理毁灭者，不能只看章节名就跳过材料来源。

## 八、三机械 Boss 后：海龟套，准备世纪之花

### 清怪与打花分开选

| 场景 | 原文推荐 |
| --- | --- |
| 日常清怪、对群 | 真断钢剑（原文「真圣剑」），作者看重其刀片命中多个敌人的能力 |
| 过渡与特殊用途 | 真永夜刃；原文还提到花后直线拉扯蛾怪时的用途 |
| 非站桩打法挑战世纪之花 | 光辉飞盘，或叶列茨球／代码 2／开发者悠悠球 |

作者**不推荐用真断钢剑作为本路线的打花主手**，不要因为它清怪好用就只带这一把。

![[天玟战士流程-原图23.jpeg]]

**防具：**海龟套。原文列出 65 防御、15% 减伤，作为这一阶段的高生存核心。对巨型陆龟的换血评价属于经验描述，探索时仍需规避冲撞。

**饰品取舍：**继续使用翅膀／气球、盾牌、星星面纱、蠕虫围巾、混乱之脑与手套的框架。

- 需要更高输出：烈火手套替换狂战士手套。原文将其概括为用防御换伤害和持续伤害，不应把持续伤害数值视为所有敌人上都固定有效。
- 使用悠悠球：悠悠球袋替换一只手套。
- 使用莉莉丝项链：作者同时保留狂战士手套和烈火手套；专家模式仍需按格子数删减。

## 九、世纪之花后：泰拉刃成型

### 核心武器

| 武器 | 定位 | 原文用法 |
| --- | --- | --- |
| 泰拉刃 | 全能主手 | 花后推进日食取得所需材料，兼顾对单与对群，可继续用到四柱 |
| 吸血鬼刀 | 恢复副手 | 配合高生存战士装备提高续航，受伤后切出使用 |
| 钥匙剑 | 地面辅助副手 | 原文称其为更强的晶光刃，插地清理地面敌怪 |

![[天玟战士流程-原图28.jpeg]]

**防具：**继续穿海龟套。

**常规路线饰品候选：**花后翅膀、气球、忍者大师装备、英雄护盾／冰冻护盾、星星面纱、蠕虫围巾、混乱之脑。缺输出时，用狂战士手套或烈火手套替换围巾／混乱之脑中的一件。

**花后翅膀候选：**骨之翼、幽灵之翼、蛾怪之翼、悬浮板，按材料、性能和操作习惯选择。

**莉莉丝路线：**气球、英雄护盾／冰冻护盾、星星面纱、蠕虫围巾、混乱之脑、狂战士手套、烈火手套；这仍是大师 7 格框架。

> [!note] 吸血鬼刀的获取与恢复
> 吸血鬼刀来自猩红宝箱路线，获取时需满足对应宝箱与钥匙条件。
> 原文以「每秒回复 30」描述它的续航强度，但实际恢复受命中、目标、吸血资源与相关限制影响，不是被动恒定回血，也不能保证站着硬吃任何 Boss。

**泰拉刃操作：**作者建议有足够生存和安全窗口时，让刀身也命中来增加输出。不要把「收益翻倍」理解为所有距离、所有命中情况下的固定倍率。

### 甲虫套：优先防御分支

- **防御分支：**作者建议常驻，尤其是打高伤害敌人或准备月亮领主时。
- **进攻分支：**相对安全、重视击杀效率时考虑，例如三级撒旦军队或双月事件。
- 原文提到的 **45% 减伤**是防御分支相关效果叠满时的描述，不能理解为穿上后始终无条件维持，也不能与其他减伤直接相加。

### 常规飞行路线

原文后期的 7 格基础框架为：

1. 猪龙鱼公爵／光之女皇／双足翼龙翅膀。
2. 翱翔徽章。
3. 忍者大师装备。
4. 英雄护盾／冰冻护盾。
5. 星星面纱。
6. 蠕虫围巾。
7. 天界壳。

**取舍：**使用泰拉刃、无头骑士剑时，作者建议可用狂战士手套／烈火手套替换围巾或部分机动格。替换机动饰品前，应先确认自己还保留足够的移动能力。

**天界壳：**作者尤其重视其夜间综合增益，原文列出 15% 伤害、4% 暴击、15% 近战攻速、7 防御及生命恢复加成；这些是作者所列的夜间情境，不能照搬成全天属性。

**防具：**甲虫防御套，原文认为四柱与月亮领主伤害高，不推荐这一阶段换进攻分支。
